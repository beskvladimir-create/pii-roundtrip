# pii-roundtrip для macOS и Windows

[English version](README.md)

Приложение для тех, кто не работает с командной строкой. Перетащите документ, отправьте очищенную версию в любую нейросеть, верните её ответ и получите его с настоящими именами, номерами и адресами. Всё работает на вашем компьютере.

## Скачать

Установщики приложены к последнему выпуску на [странице выпусков](https://github.com/beskvladimir-create/pii-roundtrip/releases): `pii-roundtrip-mac.dmg` для macOS и `pii-roundtrip-windows-setup.exe` для Windows. Каждый весит около 2 ГБ, потому что модели распознавания внутри: после установки интернет не нужен. В описании выпуска указаны контрольные суммы SHA-256 обоих файлов.

Требования:
- macOS 14 (Sonoma) или новее на Mac с процессором Apple (M1 или новее). Mac на Intel не поддерживаются.
- Windows 10 или 11, 64-бит. Версия для Windows пока бета: она собирается и проверяется сценарным прогоном установленной программы на машине Windows, людьми ею пока пользовались мало.

Приложение пока не подписано, поэтому перед первым запуском система спросит разрешения один раз.

На Mac:
1. Перетащите pii-roundtrip в папку «Программы».
2. Откройте его. macOS предупредит, что разработчика не удалось проверить.
3. Откройте «Системные настройки», раздел «Конфиденциальность и безопасность», и нажмите «Всё равно открыть» рядом с сообщением о pii-roundtrip.

На Windows:
1. Запустите `pii-roundtrip-windows-setup.exe`. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».
2. Установщик ставит программу для вашего пользователя, без прав администратора, и добавляет её в меню «Пуск».

Приложение не проверяет обновления, потому что не выходит в сеть. О новых версиях сообщается на [pii-roundtrip.besk.tech](https://pii-roundtrip.besk.tech/ru/) и на странице выпусков.

## Как это работает

1. Перетащите в окно файл Word, PDF или текст, или вставьте текст через ⌘V (на Windows Ctrl+V). Личные данные заменяются метками вида `[PERSON_1]` или `[INN_1]`.
2. Сохраните очищенный файл в том же формате или скопируйте текст и отправьте в нейросеть.
3. Когда придёт ответ, вставьте его через ⌘V (Ctrl+V) или перетащите файл, который вернула нейросеть. Приложение само найдёт нужный документ и вернёт настоящие значения, русские имена в нужном падеже.

Что сохраняется при восстановлении:

| Что вернула нейросеть | Результат |
| --- | --- |
| Текст в чате | Значения возвращены, имена склонены по смыслу |
| Файл Word | Значения возвращены в документ нейросети, его оформление сохранено |
| Новый PDF с текстом | Значения возвращены в вёрстку нейросети |
| Ваш очищенный файл без изменений | Ваш исходный файл, байт в байт |
| PDF, где страницы перерисованы картинками | Значения возвращены, простая вёрстка, с объяснением почему |

## Конфиденциальность

- Приложение само запрещает себе сетевые соединения, в нём нет телеметрии и учётных записей.
- Связь меток с настоящими значениями хранится зашифрованной (AES-256-GCM): на macOS в папке `~/Library/Application Support/pii-roundtrip` с ключом в Связке ключей macOS, на Windows в папке `%APPDATA%\pii-roundtrip` с ключом в диспетчере учётных данных Windows.
- В очищенном файле Word стираются автор и другие свойства. Очищенный PDF пересобирается так, что скрытые значения удалены из файла, а не просто закрыты. Перед сохранением приложение проверяет все части файла на остатки скрытых значений.
- Распознавание не идеально: на отложенном наборе 7 движок 0.5 оставляет хотя бы одно значение в 0,3% русских и 0,2% британских документов (см. [отчёт](../REPORT.md)). Прочитайте очищенный текст перед отправкой.

## Сборка из исходников

```bash
cd desktop
uv sync --extra models                          # окно, движок и его модели
PYTHONPATH=.. uv run python -m pii_roundtrip_desktop
uv run pytest -q
```

Установщик на macOS:

```bash
PYTHONPATH=.. uv run python scripts/collect_models.py   # закреплённые версии моделей в build/models
PYTHONPATH=.. uv run pyinstaller -y pii-roundtrip.spec  # dist/pii-roundtrip.app
./dist/pii-roundtrip.app/Contents/MacOS/pii-roundtrip --selftest
./dist/pii-roundtrip.app/Contents/MacOS/pii-roundtrip --uitest uitest   # проходит окно, снимки в uitest/
bash scripts/make_dmg.sh 0.5.3                          # dist/pii-roundtrip-0.5.3.dmg
```

На Windows те же шаги собирают `dist\pii-roundtrip\pii-roundtrip.exe`, а `iscc /DVersion=0.5.3 scripts\windows.iss` делает установщик. Сценарий `.github/workflows/windows.yml` делает это на машине Windows у GitHub, запускает `--selftest` и `--uitest` у установленной программы и прикладывает установщик к выпуску.

У приложения своё окружение, чтобы его библиотеки не меняли окружение бенчмарка. Лицензии компонентов перечислены в окне «О программе» (ссылка «Лицензии компонентов») и поставляются вместе с приложением.
