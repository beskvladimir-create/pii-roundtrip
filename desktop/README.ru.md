# pii-roundtrip для macOS

[English version](README.md)

Приложение для тех, кто не работает с командной строкой. Перетащите документ, отправьте очищенную версию в любую нейросеть, верните её ответ и получите его с настоящими именами, номерами и адресами. Всё работает на вашем Mac.

## Скачать

Установщик приложен к последнему выпуску приложения на [странице выпусков](https://github.com/beskvladimir-create/pii-roundtrip/releases). Он весит около 2 ГБ, потому что модели распознавания внутри: после установки интернет не нужен.

Требования: macOS 12 или новее, процессор Apple (M1 или новее).

Приложение пока не подписано сертификатом Apple, поэтому перед первым запуском macOS спросит разрешения один раз:

1. Перетащите pii-roundtrip в папку «Программы».
2. Откройте его. macOS предупредит, что разработчика не удалось проверить.
3. Откройте «Системные настройки», раздел «Конфиденциальность и безопасность», и нажмите «Всё равно открыть» рядом с сообщением о pii-roundtrip.

## Как это работает

1. Перетащите в окно файл Word, PDF или текст, или вставьте текст через ⌘V. Личные данные заменяются метками вида `[PERSON_1]` или `[INN_1]`.
2. Сохраните очищенный файл в том же формате или скопируйте текст и отправьте в нейросеть.
3. Когда придёт ответ, вставьте его через ⌘V или перетащите файл, который вернула нейросеть. Приложение само найдёт нужный документ и вернёт настоящие значения, русские имена в нужном падеже.

Что сохраняется при восстановлении:

| Что вернула нейросеть | Результат |
| --- | --- |
| Текст в чате | Значения возвращены, имена склонены по смыслу |
| Файл Word | Значения возвращены в документ нейросети, его оформление сохранено |
| Новый PDF с текстом | Значения возвращены в вёрстку нейросети |
| Ваш очищенный файл без изменений | Ваш исходный файл, байт в байт |
| PDF, где страницы перерисованы картинками | Значения возвращены, простая вёрстка, с объяснением почему |

## Конфиденциальность

- Приложение само запрещает себе сетевые соединения, в нём нет телеметрии и учётных записей.
- Связь меток с настоящими значениями хранится зашифрованной (AES-256-GCM) в папке `~/Library/Application Support/pii-roundtrip`, ключ лежит в Связке ключей macOS.
- В очищенном файле Word стираются автор и другие свойства. Очищенный PDF пересобирается так, что скрытые значения удалены из файла, а не просто закрыты. Перед сохранением приложение проверяет все части файла на остатки скрытых значений.
- Распознавание не идеально: на отложенных тестовых документах движок оставляет хотя бы одно значение в 0,2% русских и 0,9% британских документов (см. [отчёт](../REPORT.md)). Прочитайте очищенный текст перед отправкой.

## Сборка из исходников

```bash
cd desktop
uv sync --extra models                          # окно, движок и его модели
PYTHONPATH=.. uv run python -m pii_roundtrip_desktop
uv run pytest -q
```

Установщик:

```bash
uv run python scripts/collect_models.py         # закреплённые версии моделей в build/models
uv run pyinstaller -y pii-roundtrip.spec        # dist/pii-roundtrip.app
./dist/pii-roundtrip.app/Contents/MacOS/pii-roundtrip --selftest
bash scripts/make_dmg.sh 0.3.0                  # dist/pii-roundtrip-0.3.0.dmg
```

У приложения своё окружение, чтобы его библиотеки не меняли окружение бенчмарка. Лицензии компонентов внутри приложения перечислены в окне «О программе» (ссылка «Лицензии компонентов») и лежат рядом с ним в установщике.
