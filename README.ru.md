# pii-roundtrip

Локальная обратимая анонимизация русских и британских документов для работы с внешними нейросетями и открытый воспроизводимый бенчмарк существующих инструментов.

pii-roundtrip заменяет персональные данные в документе согласованными метками вида `[PERSON_1]` или `[SNILS_1]`. Соответствия хранятся в зашифрованном локальном хранилище, а исходные значения возвращаются в ответ нейросети. Документ можно отправить в любую внешнюю нейросеть, а персональные данные остаются на компьютере. После однократной загрузки моделей всё работает без сети.

## Зачем

Существующие открытые инструменты хорошо работают на коротких сообщениях, но пропускают персональные данные в синтетических документах, похожих на настоящие: договорах, письмах, кадровых документах, выписках. Ниже доля документов, в которых после очистки осталось хотя бы одно исходное значение. Замер сделан на отложенном наборе 6. В нём 1 000 синтетических документов на язык, номера записаны цифрами, через точки, с опечатками и словами. Набор сгенерирован после изменений версии 0.4, опубликован вместе с правилами до первого запуска и прогнан один раз ([HOLDOUT.md](HOLDOUT.md)). Ни один инструмент, включая pii-roundtrip, на нём не разрабатывался.

## Приложение для macOS

Для тех, кто не работает с командной строкой: перетащите файл Word, PDF или текст, отправьте очищенную версию в любую нейросеть, верните её ответ и получите его с настоящими значениями. Оформление сохраняется там, где это позволяет файл, модели внутри установщика, приложение работает без интернета. Установщик на [странице выпусков](https://github.com/beskvladimir-create/pii-roundtrip/releases), подробности в [desktop/README.ru.md](desktop/README.ru.md).

## Быстрый старт

Нужны Python 3.12 или новее и [uv](https://docs.astral.sh/uv/). pii-roundtrip устанавливается из исходников: он зависит от pii-guard, закреплённого на коммите в GitHub, и не опубликован в PyPI.

```bash
git clone https://github.com/beskvladimir-create/pii-roundtrip.git && cd pii-roundtrip
uv sync --extra all
uv run pii-roundtrip download-models          # один раз, нужна сеть
```

Части установки: `ru` добавляет pii-guard (распознавание и склонение русских имён), `gliner` добавляет GLiNER Guard Omni, `all` ставит обе, `bench` ставит все сравниваемые инструменты. Без них работают только правила: номера с контрольными суммами, длинные номера, имена с обращением и хранилище.

Командная строка:

```bash
uv run pii-roundtrip anonymize -l ru -i dogovor.txt -o dogovor.clean.txt --vault dogovor.vault
# отправьте dogovor.clean.txt в нейросеть, сохраните ответ в answer.txt
uv run pii-roundtrip restore -i answer.txt -o answer.restored.txt --vault dogovor.vault
```

Пароль хранилища берётся из `--password-file`, из `PII_ROUNDTRIP_PASSWORD` или запрашивается. Выходные файлы пишутся с правами 0600. Для британских документов укажите `-l en-GB`. Флаг `--append` продолжает тот же диалог, `--force` перезаписывает существующее хранилище, `--encoding cp1251` читает старые файлы.

Python:

```python
from pii_roundtrip import anonymize, deanonymize

clean, session = anonymize(text, "ru")
answer = call_your_llm(clean)          # нейросеть видит только метки
print(deanonymize(answer, session))   # исходные значения возвращаются локально
```

Для следующих сообщений диалога передавайте в `anonymize` ту же `session`. Тогда известные люди и номера сохранят свои метки.

## Как устроено

- **Распознавание.** Используются три источника:
  - pii-guard (правила с контрольными суммами и ruBERT) для русского;
  - GLiNER Guard Omni для обоих языков;
  - собственные правила: номера с проверкой контрольных сумм (СНИЛС, ИНН, паспорт, карты, NHS, NI, IBAN), длинные номера с любыми разделителями, номера словами, организации, индивидуальные предприниматели, имена с обращениями и инициалами, даты рождения по контексту.
- **Согласованность по документу.** Найденное один раз имя, организация или номер скрывается во всём документе и в следующих сообщениях сессии. Это касается падежных форм, заглавных букв, ё/е, двойных фамилий и апострофов. Разные люди никогда не получают одну метку, неоднозначное упоминание получает свою.
- **Восстановление.** Метка принимается с изменённым регистром, лишними пробелами и припиской, которую добавила нейросеть. С версии 0.3 также с потерянной скобкой (`[PERSON_1` или `PERSON_1]`) и со словами, которые нейросеть вписала в скобки перед меткой (`[г-н PERSON_1]`). Русские имена возвращаются в падеже, которого требует контекст.
- **Хранилище.** AES-256-GCM, ключ из пароля через scrypt, атомарная запись, права 0600, по символическим ссылкам не пишет.

Метки показывают тип значения, например `[PASSPORT_RU_1]` или `[NHS_1]`. По их нумерации видно, сколько значений каждого типа в документе.

## Бенчмарк

Дополнительно нужны [Ollama](https://ollama.com) с моделями `qwen3.5:9b` и `gemma4:12b` и около 20 ГБ свободного места. Полный прогон на ноутбуке занимает несколько часов.

```bash
ollama pull qwen3.5:9b && ollama pull gemma4:12b
scripts/reproduce.sh
```

Методика коротко:
- **Без домашних наборов.** Для вердикта каждый инструмент оценивается только на наборах, которые делали не его авторы.
- **Отложенные наборы.** Синтетические наборы генерируются до изменений движка, которые они проверяют, и фиксируются хешами SHA-256 ([HOLDOUT.md](HOLDOUT.md)). Каждый инструмент прогоняется на наборе один раз, с закоммиченного кода, каждый прогон записан в журнал. Наборы 1 и 2 проверяли версию 0.1. Набор 3 проверял кандидата версии 0.2, после чего его ошибки были разобраны, поэтому наборы с 1 по 3 стали данными для разработки. Набор 4 заморожен до этого разбора и проверял версию 0.2. Набор 5 проверял версию 0.3. Набор 6 проверяет версию 0.4; он сгенерирован после изменений 0.4 и опубликован вместе с правилами и планом прогона до первого запуска.
- **Одни и те же данные.** pii-roundtrip сравнивается с каждым инструментом ровно на тех наборах, на которых оценивается этот инструмент.
- **Точность.** Для каждого инструмента в отчёте приведена доля скрытых фрагментов, содержащих персональные данные.
- **Что значит «скрыто».** Значение скрыто, если скрыты все его значимые слова. Утечка означает, что исходное значение осталось в очищенном тексте. Номер ищется с любыми разделителями, русская фамилия во всех падежах.
- **Полный цикл.** Метки, выданные инструментом, и метки, выдуманные нейросетью, считаются раздельно. Интервалы считаются бутстрепом по ответам.

## Ограничения

- На коротких русских сообщениях hivetrace движок скрывает лишнее чаще, чем pii-guard: персональные данные содержат 89,2% скрытых им фрагментов против 96,5% у pii-guard. Это ошибки компонента GLiNER на разговорном тексте: за персональные данные он принимает обычные слова и сленг. На документах точность движка самая высокая среди инструментов, которые находят имена.
- Синтетические документы создаёт генератор этого проекта. Отложенные наборы защищают от подгонки под конкретные документы, но не под стиль генератора. pii-roundtrip разрабатывался на документах этого генератора, остальные инструменты их не видели.
- pii-guard и GLiNER Guard, на которых построен pii-roundtrip, выпущены авторами обоих русских внешних наборов.
- Номера NHS во внешнем наборе подставлены в американский контекст.
- Полный цикл проверен на двух локальных нейросетях. Крупные облачные модели могут искажать метки иначе.
- promptShield работает только в браузере и не измерялся.
