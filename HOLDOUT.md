# Отложенные наборы

[English version](HOLDOUT.en.md)

Четыре отложенных набора синтетических документов служат для проверки движка на данных, которые он не видел при разработке. Каждый сгенерирован до соответствующих изменений движка, его SHA-256 зафиксирован ниже, прогон на нём выполнен один раз.

Генератор в этом репозитории воспроизводит все наборы побайтно. Faker берёт часть значений (год в адресе почты) из промежутка до «сегодня», поэтому генератор фиксирует эту дату: по умолчанию 13.10.2026, для набора 3 она указана в команде (`--now 2026-10-16`). До 16.10.2026 дата не фиксировалась, и повторная генерация набора 2 в другой день расходилась с файлом в одном адресе почты из 100 документов; сам файл набора и его хеш не менялись. Проверка:

```bash
uv run python -m bench.generator.generate --seed 20261013 --out data/holdout
uv run python -m bench.generator.generate --seed 20261014 --hard 0.3 --out data/holdout2
shasum -a 256 data/holdout*/*.jsonl
```

Скрипт `bench/eval/holdout.py` перед прогоном сверяет хеши с этим файлом, запускается только с закоммиченного кода и записывает каждый прогон (инструмент, набор, коммит, время) в `results/holdout_runs.jsonl`. Повторный прогон того же инструмента на том же наборе скрипт не выполняет, пока не указана причина; причина остаётся в журнале. Журнал ведётся с набора 3; наборы 1 и 2 прогонялись до его появления.

## Набор 1

Сгенерирован 13.10.2026 до начала разработки движка. Прогнан на версии движка, которая была до доработки номеров.

| Файл | SHA-256 |
|---|---|
| data/holdout/ru.jsonl | `b8e0523fbaf6dca966e72343549c9c9b2158310ed6f6e041ff84d86f0a94a9ec` |
| data/holdout/uk.jsonl | `10191aa5d7e90f1684d559c471eae595638c79ec514dd54fc4abf64c10668ec6` |

## Набор 2

Сгенерирован 13.10.2026 после первого прогона и до доработки движка по номерам. Часть номеров в нём записана словами, через точки и с опечаткой в одной цифре. Пропуски таких номеров были найдены на внешнем наборе redmadrobot. Поэтому доработка проверяется на этом новом наборе, а не на том внешнем.

## Набор 3 (для версии 0.2)

Сгенерирован 16.10.2026 до любых изменений движка версии 0.2. В 10 раз больше прежних: 1 000 документов на язык, чтобы по утечкам относительно порога 2% можно было вынести вердикт. Прогнан один раз 17.10.2026 для всех инструментов, движок на коммите 5ac97ef (кандидат версии 0.2, не выпущен): утечки 0,5% (RU) и 3,7% (UK). После этого ошибки движка на наборе 3 были разобраны, и набор стал данными для разработки, как наборы 1 и 2. Результаты этого прогона сохранены в журнале `results/holdout_runs.jsonl`.

```bash
uv run python -m bench.generator.generate --seed 20261016 --per-type 200 --hard 0.3 --now 2026-10-16 --out data/holdout3
```
