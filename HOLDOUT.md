# Отложенные наборы

[English version](HOLDOUT.en.md)

Два отложенных набора синтетических документов служат для проверки движка на данных, которые он не видел при разработке. Каждый сгенерирован до соответствующих изменений движка, его SHA-256 зафиксирован ниже, прогон на нём выполнен один раз.

Генератор в этом репозитории воспроизводит оба набора побайтно. Проверка:

```bash
PYTHONPATH=data uv run python -m generator.generate --seed 20261013 --out data/holdout
PYTHONPATH=data uv run python -m generator.generate --seed 20261014 --hard 0.3 --out data/holdout2
shasum -a 256 data/holdout/*.jsonl data/holdout2/*.jsonl
```

Скрипт `eval/holdout.py` перед прогоном сверяет хеши с этим файлом.
